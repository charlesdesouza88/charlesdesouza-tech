# charlesdesouza.tech

Portfolio for **Charles DeSouza** — Creative Technologist composing systems, sound, and plates.

**Stack:** Next.js 16 · React 19 · Tailwind CSS v4 · TypeScript · Vercel

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Site copy, projects, experience, and case studies live in [`src/lib/content.ts`](src/lib/content.ts).

Case studies: `/work/mister-wiz`, `/work/soundchain`, `/work/cheftrack`.

## Deploy

Pushes to `main` deploy on Vercel → [charlesdesouza.tech](https://charlesdesouza.tech).
